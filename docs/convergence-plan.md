## 结论

需要收敛，不建议推翻重写。已有数据版本、Run、Artifact、Evidence、权限、图表编辑和报告 CRUD 值得保留。下一版本只承诺“单机小数据分析与可复核报告”，不承诺替代 Tableau、企业 BI 或通用科研平台。

检查依据：App.vue 同时管理对话、报告、图表、成员、Superset、模板与运行状态，接近千个非空行；main.py 汇聚约两千五百个非空行的路由与执行逻辑。报告重算修复应独立成模块，避免继续堆入主文件。历史 phased-delivery-plan 中部分缺口已实现，不能继续按历史清单重复开发。

## 剩余阻断项（按顺序）

1. **语义化 Claim**：当前原文基线会把正确的改写也标成待核验。重算修复只是恢复确定性事实，并非理解、证明任意改写。下一步应把指标、期间、维度、数值、单位与 Evidence 绑定，再由这些字段生成文字。
2. **模型根据结果补算**：当前深入分析仍限固定诊断，没有完整的“发现异常→选择分解维度→补算→产生解释”的动态循环。
3. **图表数值与正文一致性**：图表字段/形式检查与正文基线检查仍分离，必须补充图表数据、标题和正文结论的交叉校验，不能只凭各自有引用就通过。
4. **真实交付验收**：合成数据回归不能替代真实 DeepSeek、真实上传文件与 DOCX 逐页视觉验收；字体、标签遮挡、分页、图文对应仍需验证。
5. **运行与维护收敛**：新复杂操作逐步接 Run 持久队列/取消；按修改范围抽取报告、对话模块，不在重构期间改变 API。大报告列表需摘要分页，避免传输完整文档和结论基线。
