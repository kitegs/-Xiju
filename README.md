# Insight Studio · AI BI V2.0

面向个人与小团队的 AI 原生数据分析工作台。它不让模型直接拼图表配置或在宿主机执行任意代码，而是先将分析结果固化为可审阅、可手工编辑的结构化报告。

> 阶段 4.3（2026-08-18）已完成单机正式运行增强：默认本机所有者无需账号即可使用；科研/问卷模式新增 t 检验、ANOVA 与 Bonferroni 事后比较、卡方、相关/回归、Cohen's d、η²、Cramér's V 与样本量提示；预测改为滚动回测并输出趋势、异常和残差诊断；批准的计划在本机后台队列运行，支持取消、失败重试和完整历史。Superset 可通过服务端 Guest Token 嵌入专业页，不向浏览器泄露管理凭据。公网生产仍需企业身份认证、HTTPS、PostgreSQL/Alembic、Redis Worker、备份和对象存储。

> 核心升级第一期（2026-09-05）已加入分阶段 Token 追踪、Token 中心、Project AnalysisBrief 和三档澄清菜单。复杂报告请求会先在一张卡片中集中询问关键业务信息；用户可采用推荐值继续，但报告会明确列出“未经确认的业务假设”。Token 仅采用模型服务商返回的 Usage，本地确定性计算显示为 0，服务商未返回时不会用字符数伪造。

当前产品与架构基线已经调整为“本地优先、可验证、可编辑、可重复运行的 AI 分析报告工作台”。需求与设计见 [需求说明书](docs/requirements-vnext.md)、[详细设计说明书](docs/detailed-design-vnext.md) 和 [目标架构](docs/target-architecture-commercial.md)，完整索引见 [文档索引](docs/README.md)。

当前里程碑已可用：

- 工作区内完整读取 CSV / XLSX / XLS，明确读取模式并检测常量字段与不可用日期；
- DeepSeek 结构化规划：模型选择受控工具，后端校验工具、字段、SQL、Token 预算和执行边界；
- DuckDB 数据副本 SQL、可选 Docker Python 沙箱、工具证据回灌和分阶段 Token 记录；
- 图表工作台：字段拖拽、行列架、双指标、15 类图表入口、格式面板与 SQL 证据查询；
- 专业报告编辑器：分页画布、撤销/重做、属性面板、版本历史、PDF 打印和 DOCX 导出；
- 报告库支持按更新时间、创建时间、标题和图表数量排序；编辑器对象树支持拖拽、上移/下移与撤销重排；
- 用确定性统计工具生成 `ReportDocument 2.0`、`ChartSpec` 与 `Evidence`；
- 可审批 AI 分析计划：先查看步骤与风险，再运行画像、质量、SQL、报告和证据综合；
- 八种分析模式：智能自动、快速探索、深度分析、数据清洗、商务报告、科研统计、问卷分析、专业看板；
- 工具执行记录与证据展开：保留工具名称、耗时、输入/输出摘要和结论依据；
- 团队工作区数据与报告持久化到 SQLite；
- Superset 专业仪表盘已支持只读副本、Dataset/Chart/Dashboard 幂等发布；Cube 语义层仍以松耦合接口预留；
- 本机后台任务支持队列、逐步骤进度、取消、失败重试与运行历史；科研与问卷工具输出方法、效应量和可复现代码；
- 沙箱策略默认安全：内置分析工具直接执行，任何 LLM 生成代码不在宿主机执行。

## 离线本地启动

首次使用建议先看 [单机简短引导](docs/quick-start-local.md)，运行 `scripts/check-local-readiness.ps1` 检查现有依赖。

此版本使用本机已存在的 Python 与 Node 依赖，不需要下载容器镜像。

1. 启动 API：

   ```powershell
   Set-Location E:\BI\BI_V2.0\backend
   python -m uvicorn app.main:app --port 8010
   ```

2. 首次为前端从本机 npm 缓存安装依赖（严格离线；若本机没有缓存会失败，不会联网）：

   ```powershell
   Set-Location E:\BI\BI_V2.0\frontend
   npm install --offline
   npm run dev
   ```

3. 打开启动窗口显示的地址，默认是 `http://localhost:5174`。如果端口被其他应用占用，启动器会在 `5175`～`5190` 中自动选择可用端口。

也可以直接双击根目录的 `start.bat`：它会识别 V2 页面而不只是检查端口，启动后端、前端并打开正确页面。若启动异常，可从最小化的 “AI BI V2 API / Web” 窗口读取错误。

## 第一次体验：示例数据与对话

启动后进入“AI 分析”页，点击 **载入示例数据**。这会导入一份完全虚构的 2026 零售经营记录，不含真实个人或企业信息。随后直接输入或点击推荐问题：

1. `先介绍数据质量和字段含义，再告诉我最值得关注的三个问题。`
2. `分析各区域销售额和利润差异，指出高退货率品类。`
3. `生成一份管理层月度经营报告，包含结论、图表和行动建议。`

第三个问题会生成报告工件卡片。点击它可进入专业编辑器，在功能区、对象树、页面画布和属性面板中直接修改内容。示例的字段说明见 [samples/README.md](samples/README.md)。

## 数据预览与清洗

进入左侧“数据”即可直接查看表格、字段类型、质量评分、缺失单元格和重复记录。切换到“清洗配方”后可以按顺序添加：删除重复行、填充缺失值、转换字段类型、修剪文本空格、替换值、重命名字段和条件筛选。步骤支持上移、下移、撤销和重做；执行过的配方可在“历史配方”载入并重放。

## AI 分析计划与证据

发送问题后，系统先保存结构化计划，不立即执行。用户可检查每一步使用的受控工具和风险，选择“批准并运行”或“放弃计划”。运行完成后，对话中可展开每个工具的输入摘要、输出摘要、状态、耗时和证据编号；报告正文和属性面板中的证据也可展开查看计算方法、值和来源字段。

DeepSeek 的规划请求使用非思考 JSON 模式，避免推理 token 挤占结构化输出；正式回答采用结构化 Claim，每条事实都必须绑定 `evidence_ids`。意图、计划、图表和证据总结使用独立的带版本 Prompt；计划阶段只发送字段画像 Context Packet，不发送完整 DataFrame，证据总结也不再加载整段聊天历史。

输入框左侧提供三种服务端强制执行的权限模式：“安全模式”只直接运行画像、质量和固定统计，SQL 需批准，Python、MCP 和发布被禁止；“部分允许”直接运行只读 SQL，沙箱 Python、数据副本修改和 MCP 需批准；“副本完全访问”开放受控副本工具，但 MCP 仍受白名单限制。Superset 发布在后两种模式下也必须单独批准；任何模式都不得覆盖原始文件。

对话顶部的“分析模式”与模型、执行权限相互独立。默认“智能自动”会根据问题识别场景，也可手动指定科研统计、问卷分析或专业看板；计划卡会显示最终模式、判断原因、工具步骤和外部发布风险。

### 分析澄清与业务假设

输入框左侧的“澄清”菜单按当前对话保存：`自动`只在生成报告、创建看板、复杂分析或新业务目标时检查，`每次检查`在每次请求前检查新缺口，`关闭`直接使用已有简报。首次检查最多一次展示 8 个问题，已经回答或采用默认值的问题不会重复询问。

点击“使用推荐默认值继续”不会把默认值伪装成用户确认值。系统把它们写入 Project AnalysisBrief 的 `defaulted_keys`，并在生成报告中加入“未经确认的业务假设”提示。回答后会复用原聊天消息继续生成计划，不产生重复气泡。

### Token 中心

“设置 → Token 中心”可按阶段、模型、Run、Report 或 Dashboard 查看今天、近 7 日和累计 Token。阶段包括需求澄清、分析计划、证据结论、图表、报告和看板。界面只显示输入、缓存命中/未命中、输出和总 Token，不显示货币估算；服务商未返回 Usage 时会明确提示。

## AI 生成 Superset 专业看板

双击 `start-professional.bat` 会启动核心 V2、Superset 和独立的 `aibi-v2-mysql` 分析副本库。脚本只使用本机已有的 `apache/superset` 与 `mysql:8.0` 镜像，不联网下载；随机凭据保存在已被 Git 忽略的 `data` 目录。

进入左侧“专业”：

1. 在顶部或数据页选择数据集；
2. 点击“AI 生成看板方案”，检查图表和将执行的操作；
3. 点击“确认并发布到 Superset”；
4. 发布完成后点击“打开专业编辑器”继续调整布局、筛选和图表。

发布使用可替换的数据副本，不覆盖上传文件；重复发布同一数据集会更新既有 Dataset、Chart 和 Dashboard。Global Superstore 的验收看板包含区域销售/利润对比、销售额/利润/数量/利润率 KPI 和折扣利润散点图。

## 图表与专业报告

左侧“图表”进入独立可视化工作台。维度和度量可拖入字段架，支持第二指标、聚合、配色、图例和图表类型切换；SQL 面板对内存副本执行只读 `SELECT/WITH`。点击“插入当前报告”后，图表进入同一个 `ReportDocument`，可以继续在右侧属性面板调整。

报告每次保存前会自动保留服务端版本，可在“审阅 → 版本历史”恢复。标题栏显示服务端报告质量分；结论、行动和图表缺少证据，或正文出现未绑定证据的事实数字时，DOCX 导出会被阻止。`打印 / PDF` 使用浏览器高质量打印布局；`导出 DOCX` 由后端生成商业版 Word 文件，包含管理摘要、结论说明、行动表、图表来源、证据附录和复现代码。

点击“预览影响”只在内存副本计算，不写文件；检查前后行数与样本后，点击“确认并生成新版本”才会写出新的 CSV 数据集和配方记录。原始上传文件不会被覆盖。

## 配置 OpenAI 或 DeepSeek

进入左下角“设置 → 模型与 API”，填写 API 地址、模型和密钥后点击“保存设置”，再点击“测试连接”。

- OpenAI 默认使用 `https://api.openai.com/v1` 与 Responses API；本地界面的平衡默认模型为 `gpt-5.6-terra`。
- DeepSeek 默认使用 `https://api.deepseek.com` 的 OpenAI 兼容接口；默认模型为 `deepseek-v4-flash`。
- 只有启用某个提供商并主动发送对话时，应用才会向该提供商外发“会话文本 + 当前数据的字段/剖析摘要”。默认不会上传原始数据文件。
- API Key 不会返回给浏览器；后端以加密形式保存在 V2 本地 `data` 目录。单机加密不等同于企业密钥管理，生产部署应改用 KMS 或操作系统凭据库。

未配置任何 Key 时，对话仍可管理，示例数据仍可分析，生成报告仍使用本地确定性工具；只是不会得到云模型的自然语言扩展回答。

设置中心包含“模型与 API、常规、Token 中心、数据与隐私、集成”。当前默认是单机免登录，团队管理入口不在本阶段产品界面中展示；相关兼容代码保留供后续企业版迁移。集成页可查看 Cube、Superset 与代码沙箱的真实配置状态。

运行测试：

```powershell
Set-Location E:\BI\BI_V2.0\backend
python -m pytest -q

Set-Location E:\BI\BI_V2.0\frontend
npm run test:e2e
```

后端测试为每个用例重建隔离数据库；Playwright 启动独立 API/Vite 与临时数据目录，完成后自动清理。Global Superstore 回归固定断言总销售额、总利润、区域汇总、DatasetVersion、Run、Artifact、Evidence 和运行事件。

对本地完整数据执行商业报告验收：

```powershell
Set-Location E:\BI\BI_V2.0
python scripts\verify-commercial-report.py <Global-Superstore.csv> artifacts\global-superstore-commercial-report.docx `
  --expected-rows 51290 --expected-sales 12642905 --expected-profit 1467457.29
```

脚本会校验数据哈希、关键数值、Evidence 引用、结构化结论、行动项、质量门禁以及 DOCX 中的表格和图像数量。正式样例还需渲染为页面图片并逐页检查，脚本通过不等同于视觉验收完成。

公开仓库只提交合成样本或许可清晰的小型快照，不提交来源不明的 Global Superstore 文件。

## 安全执行边界

### 结论与证据核验（第一阶段）

保存草稿后，可在核验面板点击“重算并预览修复”，检查每项前后差异与候选质量，再确认保存版本。它基于原数据版本重算并恢复列出的系统结论，不自动认证自定义文字。预览不写报告，数据文件变动或报告已被其他操作修改时拒绝应用旧提案。

第三方集成和企业功能暂缓扩展，已有入口不删除。

新生成的报告建立服务端确定性结论基线。编辑器顶部“结论与证据核验”可展开状态、事实/解释/建议/假设及引用，并定位正文。修改后的草稿允许保存，但未核验结论阻止正式 DOCX 导出；未保存修改使上次检查失效。旧报告没有基线时需要重新生成，不会自动认证。

当前采用保守的原文与证据指纹比对，并复算已提供结构化操作数的比率、期间增长与排名。自由改写即使正确，也会标为待核验；尚未实现自动语义证明或审阅后补算闭环。单位换算与期间边界有固定测试，不能把首末期变化当成同比/环比，不能把百分比直接当百分点。原始数据真实性、因果关系、业务口径及币种仍需人工确认。当前报告生成器只自动输出区间变化，不因增加校验器而自动增加同比图。

校验不额外调用模型，0 模型 Token。

### 报告库管理

左侧“报告”提供新建空白报告、复制、重命名、标题搜索、数据集筛选和排序。每张卡片提供操作按钮及右键菜单。新建空白报告绑定当前选中的数据集（若有）；复制沿用来源报告的数据版本、内容和证据，但拥有独立报告 ID 和后续版本。

“移入回收站”需要确认，不删除原始数据、版本或证据；在“回收站”中可恢复。本轮不提供永久清空。回收站报告不能继续编辑、导出或通过报告分享接口读取。已经导出的文件或发布到 Superset 的副本不会被同步撤回。

编辑器离开和关闭页面时提示未保存修改；保存及重命名保留版本。AI 修改仍沿用原有预览与确认入口，本轮没有新增自动改写报告正文的循环。

### 可开关分析能力（单机）

在对话输入框附近打开“分析能力”：可以配置需求澄清、深入分析、报告内容审阅、图表排版和多方案对比，也可选择“快速分析 / 完整报告”预设。选择保存到当前对话；修改配置只影响后续计划，已经生成的计划使用原始配置快照。

深入分析当前仅在 1–3 轮内选择尚未完成的固定只读诊断（画像、质量、描述统计），并非任意代码 Agent。内容审阅可调用已配置模型提供意见，不能替代证据核验。未配置模型时使用本地诊断与检查，并明确显示零模型调用。组件结果可展开查看操作、意见和 Token；模型返回无效格式也会保留已收到的 Usage。

图表排版只调整本次新报告；多方案目前为本地规则生成的章节顺序提案，不自动覆盖现有报告。多表关联助手暂不可用。关闭可选能力不会关闭权限检查、基础质量检查或已有报告的确认保存流程。

普通任务（CSV/Excel 读取、字段剖析、缺失值检查、聚合、统计、图表和报告渲染）必须使用确定性内置工具，直接在服务端完成。

只有确实需要运行模型生成 Python 的任务才会进入 `app/sandbox.py`。该执行器默认关闭；启用时必须配置一个专用分析镜像，并以无网络、只读根文件系统、只读数据挂载、无 Linux capabilities、非 root 用户、CPU/内存/PID/超时限制运行。不要将通用 Docker 镜像或 Superset/Cube 容器当成代码沙箱。

普通个人模式运行 `start.bat`，不需要创建账号；本地请求会以可信本机所有者身份运行。阶段 4 专业模式运行 `start-professional.bat`。后者只使用本机已有的固定 Superset 镜像，首次启动会在 `data/superset.env` 生成随机本地密钥，不会下载镜像。专业页中的嵌入看板使用短期 Guest Token，若 Superset 未配置嵌入或令牌服务不可用，可回退到“完整编辑器”。下一阶段接入 Cube 指标定义与企业身份；Superset 保持为专业仪表盘能力，而不是 V2 核心编辑器的依赖。
