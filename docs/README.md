## 文档维护规则

1. 用户可见能力变化必须更新产品需求或对应专题设计。
2. 领域模型、信任边界、部署形态和外部依赖变化必须更新目标架构。
3. 新需求应具有稳定编号、优先级和可验证的验收标准。
4. 已实现不等于已达到商业质量；实施状态和发布门禁分别记录。
5. 旧文档不得静默删除，先标记为历史参考并保留迁移关系。
