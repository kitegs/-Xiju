# 报告结论基准 v1

## 数据身份

CI 中的 51,290 行 Global Superstore 形状数据由 `backend/tests/test_api.py::_global_superstore_csv` 确定性生成，是合成数据，不是真实 Global Superstore。不得把以下金额应用于用户导入的另一份同名文件。实际文件须另行记录 SHA-256、行数、字段与版本，并核对参考金额。

| 固定问题 | 合成数据标准答案 | 验收路径 |
|---|---|---|
| 总销售额多少？ | 53,819,405.00 | SQL 与报告 metric-sales |
| 总利润多少？ | 4,096,303.00 | SQL 与报告 metric-profit |
| 哪个区域销售额最高？ | South，13,473,090.00 | 区域汇总与报告 group-primary |
| 结论可追溯吗？ | DatasetVersion → Run → Artifact → Evidence | 现有端到端测试 |

另有四行固定零售数据：2024-01/02 与 2025-01/02，Sales=100/200/150/300，Profit=10/20/15/30，Region=West/East/West/East。标准答案：销售额 750、利润 75、利润率 10%、East 500、West 250；首末月变化 200%，不称同比。两次生成的结论基线必须相同。

## 反例

- 600 改成 900，保留原 Evidence ID：待核验。
- 将销售额引用换成数据规模引用：待核验。
- 修改 Evidence 内容或客户端伪造结论基线：不能获得认证。
- 增长的零/负基期、同比非十二个月间隔、环比非一个月间隔：拒绝。
- 百分比直接换算为百分点：拒绝。
- 并列排名 200/200/100：1/1/3。
- 新增有引用但未经确定性生成的事实文字：待核验，不以引用存在判定为真。

## 运行

在 backend 运行 `D:\PY\python.exe -m pytest -q -p no:cacheprovider`；在 frontend 运行 `npm.cmd run test:e2e` 和 `npm.cmd run build`。测试只操作隔离数据，不调用真实模型。

## 限制

基线一致是来源完整性保证，不是通用自然语言语义校验。当前不自动认证正确的同义改写、不判定因果、不证明模型建议有效；未确认假设始终明示。数学检查依赖结构化操作数，无法替代从原始文件独立复算全部数字。后续需接补算、字段/指标级 Claim 绑定以及修改提案批准流程。
