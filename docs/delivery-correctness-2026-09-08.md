# 单机交付正确性与故障验收（2026-09-08）

## 结论与适用范围

本轮完成分析口径、执行顺序、具名事实总结、专题正文、异步交付幂等和本地备份工具的修复。保持单机免登录，不下载依赖、不启动用户的 Superset、不提交 Git、不发布 GitHub、不修改原始数据。

这里的“通过”指指定样本、指定问题和已列出的故障窗口，不代表任意提示词、任意数据、任意外部工具已经具备生产可靠性。新规则用于新计划；已有报告不自动覆盖，旧计划应重新生成。

## 修复内容

- 亏损专题基础 SQL 在审批前统一成明确的只读计算：负利润记录数、亏损绝对额、全表记录数分母的亏损比例、区域/类别集中项，以及明确标识的非亏损参照组平均折扣。不是执行失败后用模板冒充模型成功。
- 后续深入分析继承 `Profit < 0`；负利润分组展示亏损绝对额。执行记录保留范围，展示的分组 SQL 包含过滤与取负步骤，可对原始数据重放。
- 折扣/比例的固定分组和趋势算子默认记录均值，不计算贡献求和；明显的 SQL `SUM(Discount)` 被拒绝而非静默改写。此规则不是完整的 SQL 语义证明，复杂别名/表达式仍需确认口径。
- 固定顺序：画像/查询/核对 → 补算 → 报告组装 → 排版/审阅 → 总结 → 原子提交交付结果。
- 总结使用 synthesis-v5：模型选择具名事实，服务端渲染摘要；解释限定于所引证据允许的含义，拒绝扩大范围的判断。保留旧协议的兼容验证入口；新执行链使用 v5。
- SQL 成功结果进入专题正文，展示实际别名与数值及范围限制；不再只显示返回行数。当前正文摘录前三条结果，完整工具结果/代码仍从证据展开查看，不宣称前三条代表完整覆盖。
- Bike 核对读取关系绑定的两份原始版本，按日期汇总小时值，对日表唯一键执行全外连接：分别计算未匹配项、逐键差额与最大绝对差额。总量相等不替代逐日核对。
- 小时需求增加小时×工作日联合均值图，明确派生字段和实际观测小时分母；不根据两个边际统计推断联合峰值。
- 报告行动正文与结构化行动同步，避免日期无效或亏损专题仍残留旧的增长建议。大类目亏损图采用横向布局。
- 保留原执行证据的 scope、aggregation、verified_scope，避免报告字段投影丢失这些元数据。旧验收运行的详细范围仍可在持久化步骤事件中追溯。
- 报告批量操作只刷新报告目录，不再触发全应用初始化而打断回收站选择。

## 故障与并发

`tests/test_delivery_process.py` 使用专属子进程 `os._exit(73)`，不是只抛一个可捕获异常：

| 强退窗口 | 重启期望与实测 |
|---|---|
| Report flush 后 | 未提交行回滚，Run 可识别为 interrupted；重试仅一份交付 |
| Artifact flush 后 | 最终事务回滚；保留已提交的中间草稿，不误报正式完成 |
| 最终 commit 前 | 同上；重试沿用稳定报告 ID |
| 最终 commit 后 | 报告、Artifact、答复和 completed 状态共同存在；拒绝再次执行完成任务 |

四个窗口均验证最终只有一份 Report、一份 report Artifact、一条最终 assistant 消息。此前已完成的事件和中间状态保留，不承诺恢复尚未提交的内存内容。

并发五次相同规划提交、五次同源重试、五次相同执行入队均测试通过。规划请求可带 `idempotency_key`，同键同内容复用任务，同键不同内容返回 409；前端为规划请求生成键。稳定报告身份来自计划消息 ID，最终答复、Artifact 与完成状态一起提交。

本轮保证范围为**单个 API 进程的异步入口**，不支持以多个 uvicorn worker 共享 SQLite 来宣称分布式 exactly-once。Superset/MCP 外部写入、模板 DOCX 文件落盘与远端系统不在这个数据库事务内，仍需单独审批和外部幂等方案，不能承诺一起回滚。

取消提示说明：已完成步骤不会撤销，已提交草稿/证据会保留；停止等待不保证服务商立即停止计算。已返回 Usage 正常累计，断网或取消时没有返回的 Usage 是未知，不能当作零 Token。备份与恢复不会退款或撤销远端操作。

## 备份、恢复和升级

新增 `scripts/local-backup.py`，仅对停止写入的单机数据目录操作。不会自动停止服务，不覆盖目标目录；逐文件 SHA-256 校验、SQLite integrity_check、拒绝路径逃逸/缺失数据库/错误版本清单/未检查点 WAL。

示例（先停止 API 和所有写入者；目标目录必须不存在）：

```powershell
python scripts/local-backup.py backup E:\BI\BI_V2.0\data E:\BI\backups\insight-20260908 --confirm-stopped
python scripts/local-backup.py restore E:\BI\backups\insight-20260908 E:\BI\restored-insight-20260908 --confirm-stopped
```

备份包括数据、数据库与本地密钥，必须私密保存，不能提交到 GitHub。默认跳过 acceptance/backups 子目录。恢复后先用独立配置将 `AIBI_DATA_DIR` 指向恢复目录验证，再决定替换正式目录；本工具不进行目录替换或删除。

回归验证：备份恢复保留数据行、文件与密钥字节；校验失败不创建恢复目录；已有目标拒绝覆盖。旧 SQLite schema 连续执行两次兼容迁移，保留已有 interrupted Run 和新增列/索引。此结果不代表任意未来版本升级无需迁移测试。
